문제

계산 자원은 많은데,
필요한 사람에게 닿지 않습니다

idle

밤과 주말에 노는 서버·워크스테이션

대학·연구소·기업·개인에 흩어진 CPU/GPU가 대부분의 시간 비어 있습니다.

queue

계산 시간을 기다리는 연구자

클러스터 대기열, 클라우드 비용, 기관 간 장벽 때문에 계산을 미루게 됩니다.

중앙 클라우드나 단일 기관이 소유하지 않고도, 이 둘을 안전하게 이어줄 방법이 필요합니다.

Pumat02
아이디어 · 품앗이

서로 일손을 보태던 방식 그대로,
계산 자원을 보탭니다

⏻

원할 때만 참여

pumat on / off로 언제든 켜고 끕니다. CPU·메모리·시간 한도는 소유자가 정합니다.

⇄

돈 없이 주고받기

토큰·암호화폐·정산이 없습니다. 기여와 사용 이력은 공정한 배분에만 쓰입니다.

◎

결과는 모두의 자산

공개 계산은 입력·원시 출력·해석 결과·출처 증명과 함께 영구 과학 레코드가 됩니다.

Pumat03
동작 방식

제출부터 공개까지, 중앙 서버 없이

Pumat04
기여자를 위한 안전 설계

내 컴퓨터를 빌려줘도 안전하도록

임의 코드 실행 없음

작업은 명령이 아니라 선언입니다. 서명된 승인 솔버(현재 Quantum ESPRESSO)만 digest로 고정해 실행합니다.

격리된 샌드박스

네트워크 차단, 읽기 전용 루트, 권한 제거, root 실행 거부. CPU·메모리·프로세스·디스크·시간 한도.

결과 봉인, 평문 즉시 삭제

계산이 끝나면 요청자만 열 수 있게 암호화하고, 워커의 입력·출력 평문은 바로 지웁니다.

문제 생기면 즉시 차단

서명된 폐기 목록으로 취약한 솔버를 막고, 소유자는 pumat off로 언제든 멈춥니다.

Pumat05
요청자 경험

올려두고 노트북을 닫아도 됩니다

$ pumat submit si-scf.yaml --detach Discovering compatible workers... 2 currently eligible Lease accepted by peer 12D3Ko...1tEP Uploading encrypted input from local disk... done Detached. The worker keeps the sealed result. $ # 나중에, 다시 온라인이 되면 자동 회수 $ pumat job status 4c2376 State: COMPLETED Total energy: -310.569142 eV
  • 입력은 내 디스크에서 워커로 직접 전송
  • 워커는 내 키로만 열리는 암호문만 보관
  • 에이전트가 다시 켜지면 알아서 받아 복호화·해석
  • 결과 폴더에 입력·출력·해석·출처가 함께 정리됨
Pumat06
신뢰와 출처

블록체인 대신, 양쪽이 서명한 영수증

모든 상태 변화는 각 노드의 서명된 해시 체인에도 기록됩니다. 영수증은 "합의된 실행"의 증거이고, 정직성은 재현으로 확인합니다.
